### 3.2 下载本地向量模型（注意网络）

本机 **`huggingface.co` 被墙、`cdn-lfs.huggingface.co` 超时**，但 **`hf-mirror.com` 可达**。
另外新版 `huggingface_hub` 默认走 **Xet 存储后端**（`cas-server.xethub.hf.co`），本机报 401/超时，
**必须禁用 Xet**：

```bash
HF_ENDPOINT=https://hf-mirror.com HF_HUB_DISABLE_XET=1 \
  "$PY" -c "from huggingface_hub import snapshot_download; \
            snapshot_download('Qdrant/bge-small-zh-v1.5', \
                              local_dir='RAG/models/bge-small-zh-v1.5', \
                              allow_patterns=['config.json','tokenizer.json','tokenizer_config.json', \
                                              'special_tokens_map.json','vocab.txt','model_optimized.onnx'])"
```

> **注意**：`hf_hub` 客户端在本机对大文件（60–90 MB）**会卡死**（`.incomplete` 停在整 40 MiB 不再增长）。
> 可靠做法是用 **curl 直连续传**：
>
> ```bash
> curl -L --retry 8 --retry-delay 3 --retry-all-errors -C - \
>   -o RAG/models/bge-small-zh-v1.5/model_optimized.onnx \
>   "https://hf-mirror.com/Qdrant/bge-small-zh-v1.5/resolve/main/model_optimized.onnx"
> # 目标大小：94781076 字节
> ```
>
> 模型来源必须是 **`Qdrant/bge-small-zh-v1.5`**（非 `BAAI/bge-small-zh-v1.5`）：
> fastembed 的权重仓库是前者，且文件名是 `model_optimized.onnx`；`config.json.hidden_size == 512`，
> 与 `.env` 的 `EMBEDDING_DIMENSIONS=512`、artifact 的 `embedding_model` 三方一致。
