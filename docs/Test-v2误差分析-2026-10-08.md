# Test v2 未命中误差分析（2026-10-08）

本报告基于真实 OpenSearch、真实 `RetrievalService` 和冻结集 `eval/rag_cases.test.v2.jsonl` 的 `A3-hybrid-rrf60` 快速回归结果。冻结集没有被修改，gold 修订只写入提案文件，避免用 test 反向调参。

## 结论

13 条质量案例在 Recall@3 小于 1。按首要根因分类：9 条是 gold 口径或等价证据标注问题，3 条是知识源内容缺口，1 条是私有等价证据未建模。当前没有足够证据把任何一条定性为纯排序故障；必须先完成等价证据修订再判断。

标注问题不能通过修改检索器解决。对这类问题，单一官方来源已经完整支持问题，却被标成必须同时命中多个冗余 chunk；正确做法是用“充分证据组”表达任一证据即可，而不是继续扩大 `top_k`。

内容缺口集中在 WHO 摘要：收缩压/舒张压的含义、长期高血压对心脏/脑/肾脏的损害、以及每日钠摄入的官方表述没有被当前摘要完整保留。官方页面已核对到这些原文语义，下一步以独立版本来源补充，保留旧来源和原有 evidence ID。

`emergency-vision` 和 `symptom-single` 最初看起来像排序问题，但复核发现 WHO 现有 chunk 已经分别直接支持“180/120 伴视力改变要急救”和“单次读数不能单独确诊”。它们属于等价证据漏标，不能先改检索器。完成 revision 后，如果 canonical 证据组仍不能进入 Top 3，才进入排序诊断。

## 修复边界

本轮不会直接修改冻结 Test v2 的问题文本或 gold，也不会把 `top_k` 从 3 扩大来掩盖排序问题。修订提案使用 `proposed_sufficient_evidence_groups` 表示“任一组内证据足够”，待独立 revision 集验证后才能进入下一版评测集。

本轮的内容修复使用新的 WHO 来源版本，不覆盖旧来源；这样既保留 Test v2 的 evidence ID 可追溯性，也能验证新增内容是否真正改善召回。修复后先跑 Dev/修订集，再用冻结 Test v2 做一次最终确认。
