## 二、核心结论

1. **混合检索显著优于任一单路**：Recall@3 从 0.829/0.857 → **0.943**（相对纯 BM25 +13.8%，相对纯向量 +10.0%）；MRR 0.688/0.767 → 0.786；nDCG@3 → 0.827。
2. **RRF k 参数不敏感**（k=60 vs k=30 指标完全一致）；候选集从 50 收窄到 20 无质量损失且 P95 更低（57.5ms）→ 生产配置取 cand=20。
3. **纯向量 Top-1 最高（0.686）**，混合略低（0.671）——语义排序上向量更准，BM25 贡献的是长尾召回，这是面试可深挖的点。
4. **延迟全配置 < 63ms（P95）**，本地 ONNX 方案延迟优势明显。
5. **⚠️ 拒答准确率全配置为 0.00**：30 条无关 query 全部硬返回 top_k，与已知 P0 缺陷（GatePolicy.TOP_K，无 vector_score 阈值）一致。评测体系已能度量该缺陷，修复后可直接复跑对比。

## 三、可直接使用的简历 bullet

- 构建 120 条标注用例的医疗 RAG 评测集与自动化评测管线，覆盖检索质量、拒答、权限安全三类场景，全程真实检索直连 OpenSearch；
- 通过五组消融实验验证混合检索（BM25 + kNN + RRF）价值：Recall@3 较纯 BM25 提升 13.8%（0.829→0.943），MRR 0.786，nDCG@3 0.827；
- 调优候选集收窄（50→20）在零质量损失下将 P95 延迟降至 57.5ms（本地 ONNX bge-small-zh-v1.5，512 维）；
- 评测体系量化定位拒答缺陷（无关 query 拒答率 0%），驱动相关性门限与 refusal 策略设计（修复后复跑对比可写入增量数字）。
